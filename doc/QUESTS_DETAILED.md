# BotaniaReforged — детализированная линия квестов

Полная спецификация для сборки квестов (FTB Quests или Advancement-дерево).
Каждый квест расписан так, чтобы его можно было заводить в редактор не думая:
что проверяет, от чего зависит, что выдаёт, какая иконка и какой текст.

**Все числа настоящие.** Стоимость маны взята из рецептов в
`NeoForge/src/main/resources/data/` (тип `botania:terrestrial_agglomeration_plate`,
тип `botania:runic_altar`), поведение машин — из кода
(`net.lmor.botanicalextramachinery`, `com.jykito.voltany`, the merged Applied Botanics),
ёмкости ячеек — из `ManaCellInventory`/`ManaKeyType` (1 байт = 500 маны).
Дизайнерская часть — только структура глав, порядок и награды.

Файл читается так: сначала общие правила (§1–§3, обязательны для всех глав),
потом главы по порядку. Внутри главы квесты идут в порядке прохождения.

---

## 1. Как читать карточку квеста

Каждая карточка имеет одинаковые поля:

| Поле | Что означает |
|---|---|
| `id` | Технический id квеста. Формат `глава.имя`, латиницей, без пробелов. В FTB Quests — поле ID квеста |
| Название | Текст заголовка, как видит игрок |
| Иконка | Предмет на аватарке квеста. Указан точным id (`botania:mana_pool`). Иконка — всегда предмет, связанный с квестом, никогда абстрактный |
| Описание | Текст в теле квеста. Первое предложение — вкус (зачем), дальше — механика (что сделать и сколько это стоит), последнее — подсказка |
| Задачи | Что проверяет выполнение. Тип: `предмет` (держать в инвентаре), `чеклист` (действие руками), `продвинутый` (потребление/условие). Указаны точные количества |
| Требует | Список `id`, которые должны быть выполнены раньше. В FTB Quests — стрелки-зависимости. Квест не виден, пока не выполнены зависимости (опция `hide_dependent`) |
| Награды | Что выдаётся. Обычные награды — всем, `на выбор` — одна из списка. Количество XP указано в уровнях ванильного опыта |
| Настройки | Нестандартные флаги FTB Quests, если нужны (`repeat`, `optional`, `hidden`) |

**Правило иконок.** Иконка = самый дорогой или самый новый предмет квеста.
Если квест про крафт машины — иконка машины. Если про генерацию маны —
иконка цветка. Если про тир слитков — иконка слитка этого тира. Плоские
абстрактные иконки (звёзды, книги) запрещены, кроме пролога.

**Правило описаний.** Описание всегда отвечает на три вопроса, в этом порядке:
1. зачем это нужно (боль, которую закрываем);
2. что конкретно сделать (механика + числа);
3. что откроется дальше (мостик к следующему квесту).

**Правило задач.** Предметные задачи — `inventory` (держать в инвентаре, не
забирается). Забираемые задачи (`consume`) используются только там, где это
прямо сказано, — обычно награда за квест и есть компенсация потраченного.
Чеклисты — для действий, которые нельзя проверить предметом (поставить блок,
убить Гайю, открыть портал).

## 2. Правила связей между квестами

1. **Каждая глава закрывается предметом-ключом.** Ключ — это предмет, который
   нужен как ингредиент в следующей главе. Лестница ключей:
   `lexica_botania` → `mana_pool` → `rune_of_mana` → `terrasteel_ingot` →
   `crystal_ingot` → `malachite_ingot` → `elven_knowledge` (портал) →
   `saffron_ingot` → `greenhouse` → `voltany:mana_generator` → `botania:mana_cell_1k` →
   `crimson_ingot` → `mazarine_ingot`.
2. **Внутри главы — цепочка, между главами — один мост.** Квесты главы связаны
   последовательно (каждый требует предыдущий). Следующая глава требует только
   последний квест предыдущей, а не каждый по отдельности. Это даёт линейный
   хребет с возможностью идти вбок внутри главы.
3. **Машина никогда не выдаётся до объяснения боли.** Перед квестом «построй
   машину X» всегда стоит квест «сделай вручную то, что автоматизирует X».
4. **Тиры машин — строго последовательно.** `upgraded_*` требует `base_*`,
   `advanced_*` требует `upgraded_*`, `ultimate_*` требует `advanced_*`. Это
   повторяет рецепты (в центре каждого тира — предыдущий), так что связь
   квестов просто отражает крафт.
5. **Гайя — ворота.** Всё, что требует `gaia_spirit`/`gaia_ingot` (малахитовый
   тир и выше, housing ячеек), не может быть закончено до первого убийства Гайи.
   Квесты это отражают: глава IV требует главу II дважды (террасталь и дух).

## 3. Правила наград

1. **Награда никогда не содержит ключ следующей главы.** Иначе игрок пропустит
   главу. Награда — это расходники, топливо, второстепенные материалы,
   небольшое количество маны в предметах (таблетки маны) или детали апгрейдов.
2. **Машина не выдаётся готовой.** Игрок крафтит машину сам — это и есть
   геймплей. Квест на машину награждает тем, что *устанавливается в* машину:
   катализатором, апгрейдом, топливом.
3. **Награда ≈ 10–20% стоимости квеста.** Если машина стоит 4 малахитовых слитка
   и блок драконита, награда — 1–2 слитка, стак лепестков, еда/уголь для теплицы.
   Исключение — пролог и глава I, где игрок бедный: там награды щедрее (до 50%).
4. **`на выбор` — для эквивалентов.** Когда игроку нужны лепестки/руны/топливо
   на его вкус, давать выбор из 3–4 вариантов, а не фиксированный набор.
5. **XP — по нарастающей.** Пролог: 1–3 уровня. Главы I–II: 3–5. Главы III–V:
   5–10. Главы VI+: 10–20. Эпилог: 30.
6. **Повторяемые квесты (`repeat`)** — только для фарма: лепестки из джейд-амарантуса,
   руда из орехида, мана из теплицы. Награда повторяемого квеста — всегда меньше
   себестоимости, иначе это дюп экономики.

## 4. Карта глав

```
Пролог    книга, живое дерево, первая аптечка        ключ: lexica_botania
Глава I   мана: цветы → разбрасыватель → бассейн     ключ: mana_pool (полный)
Глава II  руны, террасталь, терра-плита, первая Гайя  ключ: terrasteel_ingot + gaia_spirit
Глава III кристальная лестница: IAF, crystal→malachite  ключ: malachite_ingot
Глава IV  механический сад: базовые машины            ключ: base_daisy (любая base-машина)
Глава V   врата Альфхейма: портал, торговля, дракониты  ключ: открытый портал + malachite_dragonstone
Глава VI  лестница искр и катализаторы                ключ: saffron_spark
Глава VII Voltany: FE → мана                          ключ: voltany:mana_generator
Глава VIII оранжерея: FE растит цветы                 ключ: greenhouse
Глава IX  AE2: мана в ячейках                         ключ: botania:mana_cell_1k
Глава X   предельные тиры и Гайя в промышленных       ключ: crimson_ingot → mazarine_ingot
          масштабах
Эпилог    замкнутая фабрика: сад кормит сад           ключ: нет (финал)
```

Порядок глав — не вкусовщина, а следствие рецептов:

- Глава III раньше IV, потому что базовые машины строятся на `malachite_ingot`
  (терра-плита, 750 000 маны: `terrasteel_ingot` + `gaia_spirit` + `elementium_ingot`)
  и `malachite_dragonstone_block`. Без малахита машин нет.
- Глава V после IV, потому что цепочка драконитов идёт через эльфийскую торговлю
  (`malachite_ingot` + `dragonstone` → `malachite_dragonstone`), а торговля требует
  портал.
- Глава VII (Voltany) стоит раньше VIII (оранжерея), хотя обе про FE: генератор
  Voltany крафтится на манастили и жемчуге (ранняя игра), а оранжерея требует
  `crimson_ingot_block` и незеритовый блок (поздняя игра).
- Глава IX после VIII: housing ячеек требует `gaia_spirit`, а сами ячейки —
  AE2-компоненты; игроку к этому моменту нужна и Гайя, и сеть.
- Джейд-амарантус — самая ранняя машина (кристальный тир, Гайя не нужна), поэтому
  он появляется уже в главе III как «первая машина».

## 5. Пролог. Книга и первая травинка

**Цель главы:** игрок понял язык мода — живое дерево, лепестки, мана — и собрал
ручной инструментарий. Ни одной машины. Боль, которую фиксируем: «я всё делаю руками».

### `prologue.book` — Получите Лексику

| Поле | Значение |
|---|---|
| Название | Книга, с которой всё начинается |
| Иконка | `botania:lexica_botania` |
| Описание | Вся Botania описана в одной книге — Лексике. Она же показывает рецепты и подсказывает следующий шаг. Скрафтите её из книги и саженца (любого) и держите под рукой: дальше без неё никуда. Следующий шаг — живое дерево. |
| Задачи | `предмет`: `botania:lexica_botania` ×1 |
| Требует | — (стартовый квест) |
| Награды | 8 любых мистических лепестков `на выбор` (по 8 одного цвета); 2 уровня XP |
| Настройки | — |

Связь: ни от чего не зависит, виден сразу. Награда лепестками — стартовый
капитал на аптечку, ~50% её стоимости, дальше игрок добывает сам.

### `prologue.livingwood` — Живое дерево

| Поле | Значение |
|---|---|
| Название | Живое дерево |
| Иконка | `botania:livingwood_log` |
| Описание | Живая древесина — строительный материал половины Botania: из неё делаются палочки, разбрасыватели, каркасы. Вырастите дерево: костная мука на саженец, затем киньте в него Гайя-дух? Нет — пока проще: вырастите обычное дерево рядом с чистой ромашкой, и она обратит древесину и камень в живые. Добудьте 16 живых брёвен и 8 живого камня. Дальше из них соберётся аптечка. |
| Задачи | `предмет`: `botania:livingwood_log` ×16; `предмет`: `botania:livingrock` ×8 |
| Требует | `prologue.book` |
| Награды | `botania:pasture_seeds` ×16 (семена травы для цветов); 2 уровня XP |
| Настройки | — |

Связь: требует книгу, чтобы игрок сначала научился читать рецепты. Награда —
семена травы: следующий квест — цветы, и семена снимают гринд земли.

### `prologue.apothecary` — Первая аптечка и первый цветок

| Поле | Значение |
|---|---|
| Название | Лепестковая аптечка |
| Иконка | `botania:petal_apothecary` |
| Описание | Аптечка превращает лепестки в цветы. Поставьте её (лепесток + булыжник по рецепту из Лексики), киньте лепестки и семя — и заберите свой первый цветок-генератор. Рекомендую endoflame: он ест любое топливо и будет кормить вас маной до середины игры. Дальше этой мане понадобится бассейн. |
| Задачи | `предмет`: `botania:petal_apothecary` ×1; `предмет`: любой генерирующий цветок ×1 (детект по тегу `botania:generating_special_flowers`) |
| Требует | `prologue.livingwood` |
| Награды | `minecraft:coal` ×16 (первое топливо для endoflame); 3 уровня XP |
| Настройки | — |

Связь: замыкает цепочку «книга → материалы → инструмент → цветок». Награда —
уголь: игрок сразу может проверить цветок в деле, а не идти в шахту.

**Ключ главы:** `botania:lexica_botania` + ручной инструментарий. Дальше — мана.

## 6. Глава I. Река маны

**Цель:** устойчивая ручная генерация и движение маны: цветок → разбрасыватель →
бассейн → искры. Ключ главы — полный бассейн маны.

### `ch1.spreader` — Разбрасыватель маны

| Поле | Значение |
|---|---|
| Название | Разбрасыватель маны |
| Иконка | `botania:mana_spreader` |
| Описание | Цветок производит ману, но она лежит в нём. Разбрасыватель (живая древесина + золото) стреляет сгустками маны в бассейн. Поставьте разбрасыватель рядом с цветком, свяжите жезлом леса (Shift+ПКМ по разбрасывателю, потом по бассейну) — и увидите луч. Дальше бассейн начнёт наполняться. |
| Задачи | `предмет`: `botania:mana_spreader` ×1; `чеклист`: связать разбрасыватель с бассейном |
| Требует | `prologue.apothecary` |
| Награды | `botania:mana_tablet` ×1 (пустая таблетка — переносной аккумулятор маны); 3 уровня XP |
| Настройки | — |

Связь: мост из пролога. Награда — таблетка: учит переносить ману, пригодится для
терра-плиты.

### `ch1.pool` — Первый бассейн

| Поле | Значение |
|---|---|
| Название | Бассейн маны |
| Иконка | `botania:mana_pool` |
| Описание | Бассейн (5 живого камня) держит 1 000 000 маны. Это валюта всего мода: ею платят алтарь, плита, торговля. Наполните бассейн полностью — endoflame на угле сделает это за несколько минут, и вы впервые увидите, что такое «поток маны». Дальше — искры, чтобы двигать ману без разбрасывателей. |
| Задачи | `продвинутый`: бассейн с маной ≥1 000 000 (детект NBT `mana:1000000` или чеклист с ручной проверкой жезлом) |
| Требует | `ch1.spreader` |
| Награды | `botania:mana_pearl` ×4 (первые жемчужины — валюта мана-инфузии); 5 уровней XP |
| Настройки | — |

Связь: сердце главы. Задача на полный бассейн — первая «долгая» задача, учит
терпению. Награда жемчужинами открывает мана-инфузию.

### `ch1.spark` — Искры маны

| Поле | Значение |
|---|---|
| Название | Искра маны |
| Иконка | `botania:mana_spark` |
| Описание | Разбрасыватели — это трубы, искры — это сеть. Искра на бассейне отдаёт и принимает ману от соседних искр без прицеливания. Поставьте искры на два бассейна и перелейте ману из одного в другой. Дальше — функциональные цветы, которым эта сеть понадобится. |
| Задачи | `предмет`: `botania:mana_spark` ×2; `чеклист`: перелить ману между бассейнами через искры |
| Требует | `ch1.pool` |
| Награды | `botania:spark_augment_dispersive` ×1 и `botania:spark_augment_dominant` ×1 `на выбор` (первые аугменты искр); 3 уровня XP |
| Настройки | — |

Связь: закрывает базовую инфраструктуру. Награда на выбор — игрок пробует первый
аугмент и понимает механику.

### `ch1.functional` — Пять помощников

| Поле | Значение |
|---|---|
| Название | Функциональные цветы |
| Иконка | `botania:runic_altar` |
| Описание | Не вся Botania — про ману. Функциональные цветы делают работу: хopperhock подбирает предметы, rannuncarpus ставит блоки, jaded amaranthus даёт лепестки. Вырастите любые 5 разных функциональных цветов (считаются по тегу `botania:functional_special_flowers`). Дальше — руны и террасталь, где эти цветы сэкономят часы. |
| Задачи | `предмет`: 5 разных предметов из тега `botania:functional_special_flowers` |
| Требует | `ch1.spark` |
| Награды | `botania:mana_diamond` ×2; 5 уровней XP |
| Настройки | `optional` для перфекционистов: засчитывается любым набором из 5 |

Связь: мост в главу II. Награда мана-алмазами — намёк на инфузию и террасталь.

**Ключ главы:** полный `botania:mana_pool` и сеть искр. Дальше — руны.

## 7. Глава II. Руны, террасталь и первая Гайя

**Цель:** ручная терра-плита, первый террасталь, первое убийство Гайи. Два ключа
главы: `terrasteel_ingot` и `gaia_spirit` — оба понадобятся в главе III дважды.

### `ch2.altar` — Ручной рунный алтарь

| Поле | Значение |
|---|---|
| Название | Рунный алтарь |
| Иконка | `botania:runic_altar` |
| Описание | Алтарь собирает руны из маны и ингредиентов: киньте компоненты на алтарь, ударьте жезлом, дождитесь крафта. Соберите руну маны (`rune_of_mana`: 8000 маны, 5 манастили + мана-жемчуг на живом камне, рецепт — в Лексике). Это первая «дорогая» магия — дальше руны пойдут десятками. |
| Задачи | `предмет`: `botania:rune_of_mana` ×1 |
| Требует | `ch1.functional` |
| Награды | `botania:livingrock` ×32 (стройматериал для алтарных построек); 4 уровня XP |
| Настройки | — |

Связь: мост из главы I. Награда живым камнем — игроку предстоит строить площадки
под алтарь и плиту.

### `ch2.runes` — Полный набор стихий

| Поле | Значение |
|---|---|
| Название | Круг стихий |
| Иконка | `botania:rune_of_fire` |
| Описание | Для террастали нужны руны четырёх стихий и маны. Соберите по 4 руны воды, огня, земли и воздуха (рецепты — в Лексике, каждая стоит ману и простые материалы). Это гринд — и именно его в главе IV снимет механический алтарь. Запомните это чувство. |
| Задачи | `предмет`: `botania:rune_of_water` ×4, `botania:rune_of_fire` ×4, `botania:rune_of_earth` ×4, `botania:rune_of_air` ×4 |
| Требует | `ch2.altar` |
| Награды | `botania:mana_tablet` ×2 (полные, заряженные — компенсация потраченной маны); 5 уровней XP |
| Настройки | — |

Связь: фиксирует боль ручного крафта — payoff придёт в главе IV. Награда полными
таблетками возвращает часть потраченной маны.

### `ch2.terrasteel` — Первая террасталь

| Поле | Значение |

## 17. Шпаргалка для сборщика FTB Quests

1. **Глав — 12 файлов** (Пролог + I–X + Эпилог). Внутри главы квесты связаны
   цепочкой, между главами — только последний→первый. Опция глав: `hide_dependent`
   включена везде, чтобы игрок видел только актуальный фронт.
2. **Иконки** — точными id из карточек. Все id проверены по `en_us.json`,
   регистрации и (для AE2) ленгу из jar'а в Gradle-кэше; несуществующих нет.
3. **Задачи на NBT** (`ch1.pool`, `end.closed_loop`) — через `advancement` или
   `checklist` с ручной проверкой, если FTB Quests не умеет в NBT бассейна.
   Не заменять их задачами «держать пустой бассейн» — это убьёт смысл.
4. **Повторяемые** — только `ch3.blocks` и `end.gaia_trophy`. У остальных `repeat`
   выключен.
5. **Опциональные** — `ch1.functional` помечен как мотивирующий перфекционизм;
   обязательные для прохождения — все остальные.
6. **Баланс наград** — см. §3. Если меняете награду, держите правило 10–20%
   (50% только в прологах). Никогда не кладите в награду ключ следующей главы.
7. **Порядок тестирования:** пройти линию в выживании с нуля, проверяя каждый
   `Требует`. Особое внимание — `ch4.pool` (награда осознанно не содержит
   `catalyst_mana_infinity`), `ch5.market`/`ch8.upgrades_parallel` (описанные
   ловушки должны воспроизводиться), `ch10.gaia_farm` (количества должны быть
   проходимы за разумное время).
